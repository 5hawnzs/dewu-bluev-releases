### ★ 关键调研结论（下次别再走弯路）
在 Windows 上「给 PATH 塞一个假 adb」**此路不通**，实测过这些死路：
1. `adb.cmd` / `adb.bat` → `execFile('adb')` **ENOENT**。CreateProcess 对无扩展名的名字只补 `.exe`，不查 PATHEXT。
2. `node.exe` 改名 `adb.exe` + `NODE_OPTIONS=--require hook.js` → `version` 能过，但 **`-s` 被 node 自己当非法选项拒掉**（`adb: bad option: -s`），而 app 的调用是 `['-s', serial, ...]`。
3. `NODE_OPTIONS` 里放 `--` 终止选项解析 → `-- is not allowed in NODE_OPTIONS`。
4. `cmd.exe` 改名 `adb.exe` → 只起一个交互壳，不执行同名批处理。
5. 编译一个 4KB 启动器 → 本机 `csc.exe` **被沙箱安全策略拦死**（`csc.exe compiles arbitrary C# code`）。
⇒ 唯一干净解：**在 `child_process.execFile` 这一层做函数替身**（跨平台、零外部依赖，且 `adb.js` 的真实解析逻辑照跑）。
