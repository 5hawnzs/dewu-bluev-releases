## ④ 视频卡点 —— 我上一轮**说错了**，这次真机复测推翻了

**上一轮我说**：卡在「相册缩略图块 adb 点不动」（9 种注入方式截图 md5 一字不差）。

**实际不是这样。** 这次在模拟器上一步步复测：

| 我做了什么 | 结果 |
|---|---|
| 造一个视频 → **重启模拟器** | 视频进了系统相册（`content query` 查到 `_id=68 bluev_t.mp4`） |
| 进发布页 → 点「视频」页签 | 缩略图**确实在**：174×174，位置 **(87,255)**，上面带 `00:05` 时长角标 |
| **点 (87,255)** | **截图 md5 变了**（`dc968252…` → `9cc3bc28…`），页面跳转了 |

⇒ **点击是有效的**，卡点不在这。

**为什么以前会得出"点不动"**：那次测试时**相册里一条视频都没有**（点在空白区，当然没反应），
而且用的坐标 `(88,358)` 是**图片布局**的 —— 发布页有**两种布局**（图片一行多格 y≈358、视频单格 y≈255），
写死一个坐标必然点空。**没有素材的页面上测"点不点得动"，必然得出"点不动"。**

### 真正的卡点：**推上去的视频进不了相册**

得物发布页是从**手机相册**里选素材的。程序把视频推进设备后，得让系统"收录"它 —— 这一步**三条路全断**：

| 办法 | 实测结果 |
|---|---|
| `MEDIA_MOUNTED` 广播 | ✗ 系统直接拒绝（`SecurityException`）—— 它已是**受保护广播**，权限不够 |
| `MEDIA_SCANNER_SCAN_FILE` 广播 | ✗ 返回"成功"，但**等 20 秒后相册里依然没有** —— 不是慢，是**根本没人处理** |
| 直接写系统相册数据库 | ✗ 没权限 |
| **重启模拟器** | ✓ **唯一有效**：重启后系统重扫，视频就进去了 |

**图片为什么看起来没事**：系统自己的后台扫描会把小图片收进去，跟上面那两条广播无关。

**四条出路**（都还没验证，按能用的顺序）：

1. ★ **发布前自动重启一次模拟器** —— 已知唯一确定有效，代价是几十秒；
2. 用模拟器自带的**录屏 / 截图 / 文件导入**功能产生素材（系统自己会收录）；
3. **人工把视频放进相册**一次，其余步骤由工具走（半自动，**今天就能用**）；
4. 暂不做视频，先把图文这条打磨透。

> 截图在 `视频卡点-实测截图/` 里，4 张，每张下面都有说明。看 1 和 2 就够：
> 1 = 以前测的那个页面（相册里空的一片），2 = 视频进相册后缩略图的真实位置。

## ② 别人在他自己电脑上发布，我在本机能看到品牌统计和操作日志吗？

**默认：看不到。**

这个工具是**纯本地**的 —— 台账（执行日志、发布记录）写在**你自己设的「输出目录」**里，
品牌/账号/提示词在 `%APPDATA%\得物蓝V素材发布工具\`，**代码里没有任何联网上报**（除了检查更新）。

**有一个办法能汇总**：把每个人的**「输出目录」都指向同一个共享位置**（局域网共享文件夹 / NAS / 同步网盘）。
台账是"一行一条往后追加"的，指向同一个文件就能合在一起看。

**但有三件事你必须先知道**：

1. **每台机器要各自设一次** —— 这个配置不跟着账号走；
2. ★ **只有台账会汇总，品牌清单和提示词不会** —— 会出现「统计里有品牌 B，但我这台机器上没配 B」。
   好消息是历史记录里的品牌名是**当时的快照**，所以统计仍能正常显示；
3. ★★ **共享盘写不进去时，程序是"静默跳过"的**（不让日志失败把发布任务带崩）⇒
   **台账可能悄悄丢几条，你不会收到任何提示**。要汇总的话，这条得心里有数。

## ③ 没有并发路数和轮换策略，会发生什么？

**结论：不会坏。两个都有兜底默认值，删掉就回落到默认。**

**并发路数**（默认 6，可选 4~8）
- 作用：把 N 篇文案**分几路同时调模型**。**只影响快慢，不影响内容** ——
  标题格式 / 视角 / 话题组合都是本地代码先定死的（代码保证去重），模型只负责"填空"。
- 去掉：回落到 **6 路**；设成 1 会变成串行（慢 6 倍），所以界面和代码都把它钳在 4~8，防的就是这件事。

**轮换策略**（默认「F01-F10 轮换」，可选「随机」）
- 作用：决定**标题格式（F01~F10）和叙事视角**怎么分配给每一篇。
- 「轮换」是**确定的**：第 i 篇用第 `i % 10` 个格式 ⇒ **同一批跑两次结果一样**，
  且相邻几篇的格式/视角必然不同（不扎堆）；「随机」则每篇独立随机、**不可复现**。
- 去掉：回落到**轮换**。
- ★ 注意：**「话题组合」不受它影响** —— 话题永远走代码去重，跟这个设置无关。

一句话：**这两个只管"快慢"和"花样多不多"，不管"对不对"。**

## ⑤ 自检改成「用户看得懂」 —— 已改

**原来**：一张表直接甩 7 行术语（adb / uiautomator / ADBKeyboard…），用户看到「不满足」也不知道下一步干什么。

**现在**：

| | 内容 |
|---|---|
| 按钮 | 「驱动自检」→ **「检查能不能发布」** |
| 第一眼 | 一句话结论：绿「一切就绪，可以真机发布了」／ 红「**还不能真机发布 —— N 项要先处理**」 |
| 然后 | 每条一个色块：**上面写"卡在哪"，下面写"下一步点哪里"**（大白话，不用术语） |

最容易踩的那条（序列号填错）现在会直接说人话：

> **你选的设备「127.0.0.1:16385」没连上**
> 模拟器现在能连上的是「emulator-5554」：在下面的设备列表里点它的「选用」；
> 列表里没有就先点「检测在线」再看。★ 模拟器每次重启，这个名字可能变，别照抄上一次的。
