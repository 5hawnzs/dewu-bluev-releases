## 三、★★ 必须知道的一条：提速有一半在「配置层」，不在包里

这一条决定「升级到底有没有用」，请务必看：

- 盲点坐标（`166,359` / `985,1843` / `820,1857`）是写在**用户配置**里的
  （`%APPDATA%\dewu-bluev-publisher\config.json` 的 `publish.uiMap.steps / videoSteps`），
  由 `tools/fixuimap.js` **就地打补丁**。
- 而打包范围（`build.files`）**只收 `src/**/*` + `package.json`**
  ⇒ **`tools/` 根本不进安装包**；`store.js` / `clouddefaults.js` 里也**没有默认 uiMap**。
- ⇒ **结论：升级包 ≠ 别的机器自动变快。**

**要在另一台机器上也用上盲点提速**，二选一：

1. 在那台机器上跑一次 `tools/fixuimap.js`（源码仓库里的工具）；或
2. 导入一份改好的 `uiMap.json`。

（本机 `%APPDATA%\dewu-bluev-publisher\config.json` **已经**含盲点坐标，所以本机是快的。）
