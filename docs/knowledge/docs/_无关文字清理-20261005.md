## 四、看着像「废话」、其实是**功能规则/口径**，建议保留

这些删了会让人误解功能（不是沿革），所以留着：

- 颜色校验页：「★ 这一页**只提示、不拦发布**…」（不说清会被当成"校验没过就不能发"）
- 模拟器发布页：「发布完还要**回查审核状态**（创作中心 → 等级权益），**发完 ≠ 发出去了**。」
- 品牌统计页：「⚠️ 这一页统计的是**本机这个输出目录**里的记录：别的电脑各写各的目录，这里看不到。」
- 运行日志页：「与最下面的日志栏是**同一份内容**；这里筛完了再导出，导出的就是屏幕上这些。」
- 关于更新：「发现新版本**不会自动下载**，下载完**也不会自动重启** —— 两步都要你点。」
- 账号与安全：「关于这个权限的边界：它是**本机离线**的，用来防误操作、让产出可归属，**不是安全隔离**。」
