## 二、#7 视频抽帧送模型（本轮做的事）

### 你的拍板口径
> 「抽帧送模型，但是在尽可能少消耗模型费用的前提下做」

按这条办的：**出厂只抽 1 帧**（不是每秒一帧、不随视频变长而变多），帧在两台机器之间传的是**缩过的小图**，且**不给模型传视频本体**。

### 新口径（写进代码注释与说明书）
| 情况 | 行为 |
|---|---|
| 有**实拍图** | **只送图，绝不抽帧**（实拍图本来就是这件货最好的几帧，抽帧还要起 ffmpeg、白花时间） |
| 没有实拍图、**有视频** | 从视频里抽 1 帧，缩到「看图」设置里的边长，当图送 |
| 抽到的帧是**黑场/纯色** | 判定为空帧 ⇒ **一张都不送**（别拿废帧去骗模型） |
| 抽帧**失败** | **不抛、不阻断整批** —— 那一条照常往下走，如实标成「视频没抽出帧」 |
| 设置里把「抽帧张数」填 **0** | 一条都不抽（和「没填」是两件事，见下） |

### 改了什么
* **新增 `src/main/services/frame.js`**（9377 B）
  * `planTimes()` 按「等分取中」算时间点（1 帧 = 取中点，不是取第 0 秒——开头多半是黑场/转场）；
  * `probeDuration()` **优先纯 JS 读 mp4 的 moov**（根本不启 ffmpeg），只有 mkv 这类读不到才降级用 `-i` 探；
  * **读不到时长就抢首帧，绝不编一个时长出来**；
  * `looksBlank()` 采样亮度极差 < 12 ⇒ 空帧；
  * 抽帧用 `-ss` 放 `-i` **之前**（fast seek）+ `scale=…:force_original_aspect_ratio=decrease`；空帧/失败会**换候选时间点重试**；临时文件在 `os.tmpdir()`，**`finally` 里删干净**（不往你的素材目录落东西）。
* **`video.js`**：`module.exports` 补出 `runFfmpeg, explain` —— frame.js 复用**同一条** ffmpeg 通道（全程序只有这一处起 ffmpeg，三段报错解析也只有一套）。
* **出厂 `copy.llm.videoFrames = 1`**（`llmdefaults.js` + `store.js`）。★ 这里有个坑：**空串＝「没填」**，不能当 0（`Number('')` 是 0），否则「没填」会静默变成「不抽帧」。
* **`copywriter.js`** 接线：只在「有视频 & 没图 & 张数>0 & 没被取消」时抽；报告**逐行如实**写生成来源：
  * `AI 看图（模型，视频抽帧）` —— 真的看了抽出来的帧；
  * `AI 文字（模型，视频没抽出帧）` —— 有视频但没抽出可用帧；
  * `AI 文字（模型，视频没抽帧）` —— 你把张数设成 0 了；
  * `AI 文字（模型，这条没图）` —— 本来就既没图也没视频。
  三种「没看图」**分得开**，不会混成一句「这条没图」。
* 报告列说明（`aireport.js`）、设置页提示、说明书（`HELP.copy`）各补一段。

## 三、#3 现状答复（你只要结论，我没改任何代码）

**问题**：用户 A 改了 B 品牌的文案提示词，用户 C 在自己的设备上能看到吗？热词库同理。

### 结论：**看不到。两样都只存在各自那台机器上。**

**依据（代码级）**：
1. 文案提示词存在本机 `config.json` 的 `brands[].promptWrite / promptFilter`；
2. 热词库存在本机 `config.json` 的 `copy.hotwords`；
3. `cloudsync.js` 是**纯上行**：唯一上行对象是 `publish_log`（发布台账）；
4. **代码里没有任何下行拉取/合并的链路** —— 也就是说，就算你在云端手改了，App 也不会去取；
5. 看板 `web/board.html` 是**只读**的。

### 要做同步，得补 6 件事（缺一不可）
1. **云端建表 + RLS**（现在只有 `publish_log` 一张表）；
2. **`update` 权限**（或把表改成 append-only，用版本号取最新）；
3. **整条下行链**（现在完全没有：拉取 → 比对 → 合并 → 冲突怎么定谁赢）；
4. **多租户隔离**（按品牌/账号分，否则 A 家品牌串到 C 家）；
5. **身份与权限**（谁能改哪些品牌 —— 否则谁都能改别人的提示词）；
6. **品牌注册表先同步**（否则 C 拿到提示词，可他机器上根本没这个品牌）。

### 建议
* 如果只是**你自己在多台机器上搬**：先做「**导出/导入一份配置**」最省事，不用动云端（这也是目前最快能用的路）。
* 如果是**多人协作、要实时一致**：按上面 6 步做，**先做品牌注册表 + 下行链**，其余往后排。
* 顺带一句：真做同步时，**权限**那条不能省 —— 提示词等于你家的生意参数。
