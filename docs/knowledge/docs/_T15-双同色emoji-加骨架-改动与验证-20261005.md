**★ 为什么把「蓝色」写成 `{色}系`，而不是照原文的 `{色}色`：**

`{色}` 是**模型自由代入**的，不是程序替换 —— `copywriter.js:544` 把「形状示例」整条丢给模型，让模型自己把 `{色}` 换成**本行颜色**。
而本行颜色名**本身就可能带「色」字**（实测用户数据里有 `冠军白 / 樱花粉 / 光子灰 / 花灰色（加绒）`）⇒ 一旦写成 `{色}色`，遇到「燕麦色」就会产出 **「燕麦色色」** 这种病句。
`{色}系` 在各种色名上都读得通（灰系 / 藏青系 / 燕麦色系）。

## 3. ★ 这条骨架独有的风险：颜色 → emoji 覆盖率

T01~T14 的 emoji 只是行尾装饰、不带信息；**T15 是第一个把 emoji 当语义用的骨架**，所以「颜色有没有对应的 emoji」变成硬问题。

把颜色词表（`src/main/util/colors.js` 的 `LEXICON`，26 条）逐条过了一遍：

**⇒ 26 个色名里 24 个有对应 emoji，只有 `灰` / `浅灰` 没有。**

| 基础色 | 爱心 | 圆圈 | 覆盖的色名 |
|---|---|---|---|
| 黑 | 🖤 | ⚫ | 黑 |
| 白 | 🤍 | ⚪ | 白、银、冠军白、奶白 |
| **灰** | **❌** | **❌** | **灰、浅灰、光子灰、花灰色（加绒）** |
| 红 | ❤️ | 🔴 | 红、酒红、勃艮第红、樱花粉 |
| 橙 | 🧡 | 🟠 | 橙 |
| 黄 | 💛 | 🟡 | 黄 |
| 绿 | 💚 | 🟢 | 绿、墨绿、军绿 |
| 蓝 | 💙 | 🔵 | 蓝、领袖蓝、天蓝、藏青、雾霾蓝 |
| 紫 | 💜 | 🟣 | 紫 |
| 棕 | 🤎 | 🟤 | 棕、咖啡、卡其、驼、米、燕麦色、流沙金 |

三条实测结论：

1. **爱心和圆圈都没有灰色**。🩶（灰心）是 **Unicode 15 / 2022 年**才加的，老机型（含模拟器常用的旧 Noto Color Emoji）会显示成**豆腐块 □**。
   ⇒ 提示词里写明：**本行颜色是灰 / 浅灰时别用 T15，退回 T13**（不加 emoji 对）。
2. `colors.coarse()` 会把**棕 / 卡其 / 驼 / 米 / 燕麦色 / 流沙金**都判成「橙」（HSL 色相都落在 h<45）—— 但对这些色名，`🧡 橙心` 不如 `🤎 棕心` 准。所以映射表里**专门为暖棕系写了例外**（提示词里那句「棕（含卡其 / 驼 / 米 / 燕麦）→🤎/🟤」）。
3. 电商叫法靠「含哪个基础色词」兜底：`冠军白→白` ✅、`雾霾蓝→蓝` ✅、`樱花粉→红`（严格说该用粉心，但粉心也是 2022 年才有的，不划算）、`光子灰→灰` → 走灰色例外。
