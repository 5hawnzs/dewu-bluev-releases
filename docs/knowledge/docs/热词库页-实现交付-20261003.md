## 一、界面长什么样

自上而下五块：

1. **页头**：标题「热词库」＋一句口径说明「标题『产品词 + 热门词』用的词库 · 改完下一次生成就生效（不用重启）· 材质与极限词有红线挡着」；
   右上角两个按钮：**恢复内置**（清掉你的改动、回到出厂词库）／**保存**。
2. **状态条**：`内置出厂词库` / **全库 64 词 · 8 组**（改过之后这里会变成「已修改 N 词」）。
3. **「这个库是怎么被用到的」＋「三条红线」** 两块说明（红线文案与主进程**同一份**，不在界面重抄）：
   - 红线 1 材质 / 参数词不许进（鹅绒、充绒量、加厚、防风防水…）—— 那是这件衣服的客观事实，**必须图里看得见或货号有写**，词库给不了，写出来等于造假；
   - 红线 2 极限词、别的平台名不许进（最 / 第一 / 顶级 / 淘宝 / 抖音…）；
   - 红线 3 `{色}` 是**占位符**，留着它这组词才会跟着**本行给的颜色**走，删光就写死颜色了。
4. **7 个可编辑组**（风格 12 / 氛围 8 / 色感 7 / 场景 7 / 人群 6 / 季节 6 / 情绪 6）：每个词后面一个小 `×` 删；组尾一行输入框「加一个词，回车即可」＋「添加」按钮。
5. **收尾（12 词）· 已锁定，不可编辑**：灰底、词只读列出来，**一个控件都没有**；旁边写明「仍参与生成（词汇照给模型），只是不给编辑」。
6. **10 种句式骨架（T01~T10）· 不可编辑**：只读表格（编号 / 名称 / 结构 / 拉取示例）——这是**语法**，改坏直接出病句，不给动。

改 / 恢复只有管理员能做 —— 改的是**全员**的生成口径。而且不靠「藏按钮」挡：主进程那两个接口本身带管理员校验，绕界面直调也拦得住（测试里真跑过）。

3. 收尾组**锁定 ≠ 停用**：它照旧把 12 个词给模型，只是不给编辑。
