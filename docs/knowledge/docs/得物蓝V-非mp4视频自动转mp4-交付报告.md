## 二、怎么转的（策略）

新增 `src/main/services/video.js`，**两步走，优先无损**：

```
① 无损转封装  ffmpeg -c copy -f mp4
   → H.264 / HEVC 这类 mp4 容器放得下的编码：只换壳、不重编码
   → 秒级完成，画质零损失（iPhone 拍的 .mov 绝大多数走这条）
② 转码兜底    ffmpeg -c:v libx264 -crf 20 -pix_fmt yuv420p -c:a aac
   → 容器/编码放不下才走这里（如 ProRes）
```

转完**不是看文件名就算成功** —— 会解析产物核对三件事：
`ftyp` 品牌属于 mp4 家族（**`qt` 不算**）· `moov` 能读 · 视频轨编码在白名单（`avc1/avc3/hvc1/hev1/...`）。
不合格就**如实报错**，并且**先把半成品删掉**再报错，绝不把半截文件留在目录里让下游以为转好了。

**ffmpeg 从哪来**（与 adb 完全同一套三段解析）：
① 设置页手填的完整路径 → ② **程序内置**那份 → ③ 系统 `PATH` 里的 `ffmpeg`。

**转在哪**：转的是 `flat_<时间戳>` **扁平副本目录**里的那份（同卷硬链接）。
⇒ **你的原素材目录完全不动** —— 和图片合规处理是同一套规矩。

## 四、⚠️ 许可（这条你必须知道）

内置的是 **GPL-3.0** 静态构建（`ffmpeg-static` b6.1.1 = `ffmpeg 6.1.1-essentials_build-www.gyan.dev`，
`--enable-gpl --enable-version3 --enable-static`），**许可全文随包**（`resources/ffmpeg/LICENSE.txt`）。

- ✅ **只在自己公司内部装机使用** → 没问题。
- ⚠️ **如果把安装包给客户 / 外部方** → 有 **GPL 传染风险**。那时要么换
  **LGPL 共享构建**（BtbN 的 `ffmpeg-*-lgpl-shared`，动态链接 + 允许用户替换库），要么按 GPL 走完整合规
  （附源码 / 书面提供）。具体步骤我写在 `vendor/README.md` §3 了。

来源、字节数、md5 都记在 `vendor/README.md`，`uicheck` 每次回归会**逐项互校**（缺一个就红）。

## 五、顺手修掉的一个真隐患（会被这次改动引爆）

`compliance.js` 的 `syncItem()` 把 `type` **写死成 `'image'`**。
图片那几个分支用它没问题，但**视频转 mp4 之后如果复用它，会把视频静默改成图片** ——
发布时会按图文走步骤、**拿图去发视频**。

改之前它没暴露，是因为视频从来不会被 `fix()` 处理。这次一接上，它就会被引爆。已修：
改成按 `row.type` 推断 + 允许调用方显式覆盖，并加了断言守着（上面双向验证第 1 条）。

另外两处**报表口径**也一并修正：`notMp4` 按**扩展名**数、「视频超时」只数**真的超了时长**的
（加了「没找到 ffmpeg」这条新 `manual` 路径之后，原来的「视频 + manual」会算错）。

## 六、诚实说明：哪些我**没能**验到

1. **没有真实 iPhone 的 `.mov` 样本可测**。这台机器上找不到真的 `.mov` / `.m4v`
   （只有 `.mp4`），所以 `.mov` 那条路我用**合成的 `qt` 品牌 MOV**（H.264/AAC 与 ProRes 两种）验的**代码路径**，
   没有验真实 iPhone 文件的兼容性。理论上没问题（iPhone 的 `.mov` 就是 `qt` + H.264/HEVC），但**这一点我没实测过**。
   ⇒ 建议你随手丢一个真的 iPhone 视频进来跑一次「检查 → 处理」。
2. `.avi` / `.webm` / `.mkv` 我只确认了**内置 ffmpeg 支持这些容器**（`-formats` 里在），
   没像 `.mov` 那样造样本跑全链路。
3. **超 600 秒的视频不会转** —— 这是刻意的：转成 mp4 也过不了得物的时长限制，白转一次没意义，所以直接标「只标红不裁剪」。
4. **长视频转码会慢**（转码是 CPU 密集；超时上限设的 30 分钟）。这条路上没做进度条细分。
5. **取帧 / 裁图 / 传封面依然不做** —— 封面继续用「得物推荐的」。ffmpeg 现在虽然内置了，
   但这次**只加了「转格式」这一件事**，没有顺带加别的视频能力。
