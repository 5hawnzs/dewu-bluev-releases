## ★ 四件需要提前知道的事

1. **这是一个云沙箱地址**，不是我搭的长期服务器 —— 它能活多久我不能保证。
   要长期稳定或自定义域名，得另找静态托管（产物就是纯静态的两个文件，可以直接搬走）。
2. **拿到这个链接的人都能看**。匿名 key（anon / publishable）本来就是公开设计 ——
   App 安装包里内置的是同一份，数据库策略只放行「读」。
   ⇒ 想要真正的访问控制，得改成**登录后读**（接 Supabase Auth）或走服务端代理；
   **在静态页面上加个口令是挡不住人的**。
3. 看板上的「机器」是**电脑名**（`os.hostname()`），不是模拟器名。
4. 表里现在只有 4 行**连通性探针**测试数据（标着「⚠ 连通性探针（可删）」），
   等真实发布跑起来就会被真实数据淹没。
