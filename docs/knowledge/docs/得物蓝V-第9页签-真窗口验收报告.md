## 一、为什么上一轮不敢说"点过了"

上一轮那 6 张截图用的是 `el.click()`（在 JS 里直接调函数）。它有个致命问题：
**跳过了浏览器命中测试**——元素被浮层盖住、或者坐标上压根是别的东西，`el.click()` 照样"成功"。
所以它能证明"代码逻辑通"，但**证明不了"这个按钮在界面上真的点得着"**。

这一轮换了做法，见下。

## 二、怎么做到"真点"（以及三处做不到 —— 明说，不冒充）

| 手段 | 具体做法 |
|---|---|
| **真窗口** | `new BrowserWindow({ show: true, ... })`，窗口真的画在桌面上 |
| **真鼠标** | 取 `getBoundingClientRect()` 的真实中心点 → `sendInputEvent` 依次派发 `mouseMove → mouseDown → mouseUp` |
| **命中测试** | 每次点击**先用 `document.elementFromPoint(x, y)` 核对那个坐标上真的是它自己**；不是就判 FAIL，绝不"假装点到了" |
| **真键盘** | 逐字符 `char` 事件；`Ctrl+A` 用 `keyDown{A, modifiers:['control']}`；下拉框用**真方向键**改选中项 |
| **落盘校验** | 每条断言读的是磁盘上的 `config.json` / `auth.json`(**不是界面文字**)，即"真的写进去了"，不是"界面上看着对" |

### ★ 三处做不到真手点的，明写在这里

1. **中文输入**：IME 组字没法用合成事件模拟 ⇒ 中文一律走 `insertText`（等价"输入法上屏"）。
   **受影响的只有 ②③⑨ 里的中文名字**；纯 ASCII 的名字（`QA-ACCEPT` / `QA-RENAMED`）是**真键盘一个字一个字打的**，实测采到了框里的值。
2. **原生 `<select>`**：真鼠标点它会弹出**系统级下拉菜单**（独立窗口，`sendInputEvent` 到不了）
   ⇒ 改成 `focus()` + **真方向键**改选中项（不弹菜单）；**"持久化"那一步仍然是真鼠标点「设为默认」按钮**。
3. **原生 `confirm()` 确认框**：★ 自动化点不到它。我原本打算走 CDP（`webContents.debugger.attach` + `Page.handleJavaScriptDialog`），
   **实测该调用在这台机器上直接挂死** —— 用 8 秒竞速超时抓到（第一次跑因此卡了 **8 分 45 秒**才被杀）。
   ⇒ 改用"渲染层接管 `confirm`"：脚本记录参数 + 返回预设答案。
   **被替掉的只有"人按下那个按钮"这一个动作**；断言的仍然是真实行为：**点删除会不会先弹框 / 框里写了什么 / 点取消后到底删没删**。

### 隔离（重要）

`userData` 指到一个**临时目录**，本机真实的 `config.json / project.json / pool.json / auth.json` 只**拷贝**过去。
跑完核对：本机 `config.json`（品牌 `TW男装` / `TW女装`、默认品牌 `brd_mupe1a91f85b18`）、
`auth.json`（`admin` / `testbeta`）**一个字节没动**；脚本造的 `QA-*` 品牌、`qa_member` 账号**只存在于临时目录**。

## 六、顺手发现的 3 个环境事实（对以后做自动化有影响）

1. **`webContents.debugger.attach` 在这台机器上会挂死**（8 秒竞速超时抓到；一次实测卡满 **8 分 45 秒**）。
   ⇒ 想走 CDP 做 Electron 自动化（改窗口尺寸、拦截对话框、性能指标），**在这台机器上先别指望它**。
2. **可见窗口的 `capturePage()` 会抛异常**：`Current display surface not available for capture`
   —— 窗口被别的窗口盖住/那一刻没在绘制时就会这样，而且**时好时坏**（实测：同一轮里有的张成功、有的连试 3 次全失败）。
   ⇒ 脚本里已加了「提出到最前 + 5 次退避重试 + 失败不打断验收」。
   **改之前**：正式轮丢 1 张（`11b`）、破坏轮丢 5 张；**改之后**：两轮各 **17/17 全部拿到，放弃 0 张**。
   ★ 副作用要讲清楚：**跑验收时那个窗口会被强制置顶**（会弹在屏幕上），脚本结束即恢复。
3. **`auth.load()` 是"已加载就短路"**（`if (db) return db;`）⇒ 直接改 `auth.json` 文件**不会**影响运行中的进程。
