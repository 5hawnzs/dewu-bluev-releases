## 二、COS 那个地址为什么不行（已做 10 次实验）

`https://dewu-bluev-release-1499238579.cos.ap-guangzhou.myqcloud.com/board/index.html`

| 试过的手段 | 结果 |
|---|---|
| 默认域名 + `text/html` | ✗ 强制下载（响应头 `x-cos-force-download: true`） |
| 对象头改成 `Content-Disposition: inline` | ✗ 照样下载 |
| 换成 `.txt` / 无扩展名 / 大写后缀 | ✗ 照样下载 |
| 换成 `application/xhtml+xml` | ✗ 照样下载 |
| 开 COS 静态网站域名（`cos-website...`） | ✗ 同样被拦（且默认没开） |

结论：**COS 默认域名对 HTML 一律强制下载，是按内容类型拦的，改不动**；只有**绑自有域名 + CDN（要备案）**才能预览。
⇒ 那份 COS 副本**只当备份留着，不要发给别人**。（已把为测试开的静态网站设置**撤回**，没在桶里留无用配置。）
