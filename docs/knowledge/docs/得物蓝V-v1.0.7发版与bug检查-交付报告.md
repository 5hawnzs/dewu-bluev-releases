### 包内核对为什么升级成「遍历整个 asar」

上一版脚本只挑 11 个文件比对 md5 —— 那只证明「**我挑的这 11 个**是对的」，
**证明不了「包里没有我不想要的东西」**。这次改成 `asar.listPackage()` 取全部条目 → 逐个 `extractFile`
→ 拼成一个大字符串扫关键词，**并同时断言「真读到几个」**（`read>=15 && bytes>300000`），
否则「一个都没读到」和「读到的都干净」都是 0 命中，**空==空会假通过**。

**双向结论**（既证明没有，也证明还在）：
