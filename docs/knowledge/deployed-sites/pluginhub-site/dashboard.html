这些数字怎么来的：插件每次点「开始采集」往自己的数据库插一行记录（随机机器编号 + 插件名 + 版本号 + 页面名 + 时间）， 不发任何采购数据、也不含得物账号。
本页只读 —— 页面只能调用统计函数拿汇总数字，读不到任何一行明细，也不会把数字刷高。
「装过的电脑」= 记录里出现过的不同机器编号个数。
注意：得物 v1.5.7 之前的老版本走的是旧的计数服务，不在这个库里；WPS 等新插件从第一个版本起就计入。
