# 1.1.4 本地交付记录

2026-10-12。最终构建目录：`dist-1.1.4-final`。

## 本次修复

- 云端状态校验的网络错误、HTTP 错误及无效响应不再直接清除本次运行中已验证且未到期的会话。
- 只有数据库明确返回“登录已过期”、本地令牌到期或主动退出才清除会话；不会把磁盘中的记住登录记录当作首次联网验证的替代品。
- 品牌目录同步失败时保留已验证会话和原目录，下一次前台状态检查重试。联网检查每 60 秒进行一次；账号分配和目录名称、启用状态变化均触发界面更新。
- 登录页重新显示时同步进入原生登录窗口模式，收紧宽高，处理最大化及全屏，避免主窗口尺寸留下整片白色背景。
- 合并之前的用户任务品牌传递、自检输出目录隔离和正式安装版禁止模拟发布修复。

## 交付范围

本次仅构建本地安装包并准备分发文件，没有自动安装、没有上传 Release，没有修改历史业务日志或云端记录。构建成功不代表已完成用户网络环境下的持续运行验证或真机发布验证。
