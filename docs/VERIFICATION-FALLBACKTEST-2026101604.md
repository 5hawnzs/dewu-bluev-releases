# 「备用入口试发」模块验收（构建 2026101604 / 2026101605）

## 为什么要有这个模块

本机账号的个人页有「主页」按钮，主入口永远能走通，备用入口（动态流相机）在本机**没有真实触发条件**；
而远端那些没有主页按钮的账号走的正是备用那一段。只靠「本机发一遍」证明不了备用入口，
只能给一个显式的强制开关把它跑出来。

开关的语义是**「假装这台账号没有『主页』按钮」**，不是「另走一条备用路线」：
导航那一段照常跑（先点「我」、停在个人页），到「主页」那一步无论按钮在不在都当找不到，
于是**生产环境里无主页账号触发回退的那段代码**自己接管（回首页 → 点动态 → 等提示结束 → 点相机）。
这样试发跑出来的命令序列，与真的没有主页按钮的账号逐条相同。

## 改动落点

`src/main/services/publisher.js`

- `runBatch`：`ctx.forceAlternateEntry` 从 state / ctx 两处取，只影响「走哪个入口」。
- `runStep`：`(!exact.length || ctx.forceAlternateEntry)` —— 到「主页」那一步必然走回退分支。
- `runReal` 导航收集保持原样（照常点「我」）；**删掉了**原来「素材就绪后直接开备用入口」那段捷径。
- 复用判据恢复为 `ctx.publishEntryRoute === 'camera' && !uimap.isDraftScreen(...)`，与线上一致。

`src/main/jobs.js`：新增任务类型 `publish.fallbackTest`（品牌归属、类型名、批次结果口径、
队列品牌校验一并加入）；`FALLBACK_TEST_USER = 'shuo'`，`run()` 对非指定账号**直接拒绝**。

`src/renderer/app.js` / `index.html`：新增第 14 个页签「备用入口试发」，只对指定账号显示；
发布队列逐行状态、设备表刷新、停止按钮、自动扫描全部按「发布类任务」一并认它。

## 行为回归（假设备，无真实点击）

`tools/albumreadytest.js` 新增第三条轨迹 `forced`（账号**有**主页按钮 + 开关为真），断言：

- ★ 它的 adb 命令轨迹与「账号真的没有主页按钮」那条**逐条相同**（不是另走一条捷径）；
- ★ 对照：有主页按钮的主入口轨迹与备用**不同**（否则上一条等于比两份空）；
- ★ 强制备用也照着线上走：先点「我」→ 再回首页 → 点「动态」→ 点相机。

全套 `node tools/run-all.js`：**45 套、2404 项通过、0 红**（实测）。

## 真机验证（本机模拟器，真实设备与真实发布链路）

驱动：`tools/fallback-test-module-real.cjs`。它调的是**生产 publisher.run**，
只把 `state.publish.forceAlternateEntry` 置真（与界面那个页签传下来的开关同一条路），
走到「提交发布」立刻取消 —— **本轮未提交任何内容**。

实测通过，入口点击轨迹（真实 adb 坐标）：

```
945,1869   底部「我」
135,1870   （回首页后）底部「动态」
1026,81    动态流右上角的相机
```

对应日志原文：

- `当前账号页面没有「主页」按钮，切换动态流相机入口`
- `备用入口：等待相机入口及页面稳定（未点击相机）`
- `已通过动态流相机进入发布流程，跳过账号主页入口`
- 之后完整走完：清理相册 → 推送 4 张 → 索引 → 排主图 → 写媒体库 →
  选图 4 张 → 转场确认标题页 → 填标题 → 填正文 → 关联好物 → **提交前取消**

结果文件：`_scratch/fallback-test-module-real/result.json`，总耗时 70.4s。

## 权限两道门

- 渲染层：`fallbackTestVisible()` 只对 `shuo` 显示该页签（免登录开发模式放行，否则本机没法自测）；
- 主进程：`jobs.run` 对 `publish.fallbackTest` 直接拒绝非指定账号 —— 改前端一行不算数。

`tools/logintest.js` 同时钉住两侧：普通成员**拒绝 + 看不到、硬点也进不去**；
管理员**同样看不到**（它不是管理员页签）；指定账号**看得见、进得去、调用放行**（卡点落到业务前置）。

## 未覆盖 / 如实留着

- 远端无主页按钮账号的实际连续发布仍要由那台设备的真实任务结果关闭，本机结果不能冒充。
- 「点相机后弹窗遮挡」这类现场由假设备用例覆盖，真实系统浮层仍需对应设备实测。
- 试发的失败原因要看运行日志；该页**没有**「重跑」列（避免一键重发）。
