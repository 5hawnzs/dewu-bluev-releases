## 修复和验证

- 配置 IPC 改为字段白名单；不能借此改品牌注册表、同步目标或成员无权配置的外部程序。
- 对象树拒绝危险原型字段及过深嵌套；配置读取仅访问自有属性。
- IPC 仅接受应用入口主框架；真实 Electron 测试验证其他本地页面加载同一 preload 也无法调用。
- 开启渲染沙箱，拦截页面跳转、弹窗、webview 和浏览器权限，收紧 CSP。
- 品牌目录和配置只向成员返回其授权品牌；动态 ID 做 HTML 转义。
- 文件打开仅接受目录及数据文件，拒绝脚本、程序、快捷方式等可执行内容。
- Excel 解压前验证 ZIP 目录、压缩大小、总解压大小和实际解压长度，拒绝公式/非文本词条。
- ADB 对含反斜杠的 ASCII 文本改用 B64 输入，防止引号转义被抵消；媒体扫描路径统一转义。
- 正式包不接受开发免登录/本机账号环境开关；权限拉取失败时清除内存身份。
- 修复词库去重误丢 `constructor` 等继承属性同名词的问题。
- Electron 升至 44.7.0，sharp 升至 0.35.5，构建工具及传递依赖同步修补。`npm audit` 全依赖扫描为 0 条已知漏洞；这不等于证明没有未知漏洞。

## 云端还需执行

在原账号服务的 Supabase 项目 SQL Editor 执行 `docs/supabase-auth-security-migration.sql`。它只替换三个函数，不重建账号、不重置密码、不生成初始化码：

- 同一账号的并发密码检查串行执行；管理员管理操作加事务锁。
- 创建成员至少有一个启用品牌；删除成员最后一个品牌前要求重新分配。
- 改密码时撤销其他设备旧会话，保留当前会话。

补丁已使用真实 PostgreSQL 引擎 PGlite 与 pgcrypto 隔离执行，验证权限拒绝、六次失败锁定、旧会话撤销及重复执行保持账号。当前没有该项目数据库管理员连接，因此未冒称线上已经应用。

## 防护边界

公开看板的日志读写范围沿用用户已授权的设置，本次没有私自改变访问策略。客户端内置的组织模型密钥可以被拥有安装包的人提取；彻底隐藏需要服务器代理。能控制本机文件/进程的攻击者也不受客户端 UI 权限保护。以上不属于“扫描为零”能消除的风险。

同版本覆盖必须重新下载安装；客户端自动更新仍按用户要求关闭。运行时升级使安装包约增加 30 MiB；测试用 PostgreSQL 依赖仅为开发依赖，不打入安装包。
