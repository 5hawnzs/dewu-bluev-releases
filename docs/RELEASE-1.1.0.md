## 处理目录与本地报告入口修复

文案生成选择当前批次的原目录 A 时，改用已经整理、合规处理的副本 B。报告直接保存在实际使用的批次根目录，报告中的素材路径和导入后的发布队列均来自 B。B 被移动或删除时明确报错，禁止退回未处理的 A。独立选择其他批次仍使用该批次自己的目录。

生成完成后显示带下载图标的小报告按钮，点击直接通过本机默认软件打开刚生成的 Excel。取消自动弹出资源管理器，不通过云端打开，不复制文件或新建目录；打开失败显示原因。
