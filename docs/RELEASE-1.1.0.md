# v1.1.0 交互修复

2026-10-10，基于 aa4b663，用户指定最终版本为 1.1.0。

- 在线文案模型默认开启，模型弹窗不再提供离线模板选项；解释 API 服务地址、Key 和模型的对应关系。送图、张数及缩放参数灰置，保存模型时不改动这些原有参数。
- 选择新素材目录或完成整理后清除上一批合规报告、统计和分组，点击检查前显示待检查。视频时长先解析 MP4 元数据，失败时用内置 ffmpeg 备用探测；损坏文件保持未知。非素材文件仍可隔离，仅有待隔离项时显示卡片。
- 文案素材目录选择器打开生成目录的母目录。
- 发布页顶部仅保留导入、停止和开始；两个导出收进折叠区，连接由现有设备扫描完成。隐藏通道、定位步骤和批次等内部提示，删除手动输入序列号入口。
- 未安装得物时停止后续无意义检查，只提示安装问题，并提供直达设置页下载或安装按钮。
- 发布间隔默认连续；旧配置首次升级迁移一次，之后保留用户自行选择的间隔。所有应用标题统一为“得物蓝V素材发布工具”。
- 登录期间主界面使用 hidden 与 inert；身份验证不再提前放大窗口。首页配置、工程和日志并行加载，准备完毕后经受登录保护的 IPC 放大窗口，再互斥切换两棵界面树。防止重复登录与并发初始化。

回归入口为 `node tools/run-all.js`。新增行为用例覆盖旧合规结果清除、时长备用探测、受限模型参数保存、目录选择器、发布页入口、得物下载导航、默认值升级和延迟登录。

最终源码完整执行 25 套回归，1879 项断言全部通过；其中界面 270 项、登录 128 项、登录窗口 20 项、设备发布后端 407 项。登录专项额外独立重复两次，每次 128 项全部通过。

测试均使用隔离的账号、素材与模拟设备；没有对真实得物账号执行发布。慢加载由延迟首页 IPC 复现，不代表已覆盖所有低性能电脑的硬件环境。

本次无需新的云端 SQL 迁移，安装包不增加运行依赖。
