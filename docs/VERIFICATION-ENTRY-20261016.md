# 2026-10-16 发布入口修复验收

## 问题与实现
非 rich 账号无「主页」时，浏览导航通过备用相机进入相册，但 publishEntryReady 写入了临时 ctx，主流程仍查 rlPublish。备用入口还可能与素材索引并行。

修复在 src/main/services/publisher.js：浏览导航只浏览，缺少主页时将入口步骤留至相册就绪后；备用入口在主 ctx 中执行并回读前台，只有实际进入发布流程或草稿箱才记成功。后续旧账号入口步骤跳过。
已成功走通的备用路线只在本批共享，下一批（即使复用同一 ctx）清空。返回草稿箱仍沿用草稿箱出口，不强停或重启得物。
草稿检查默认顺序为入口之后、选图之前，没有证据支持后移；状态改为「检查草稿箱」「检查继续编辑提示」，保留屏幕条件，不因显示名称而点击。
