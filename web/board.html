连接设置

已经按组织预填好了，直接点「保存并连接」就行（要换成别的项目就直接改这两个框）。 填过的值只存在这台浏览器的 localStorage 里，不上传到别处。

★ 这里只能填 anon / publishable key（它本来就是公开设计、靠数据库的行级策略收口）。 绝不要把 service_role / secret key 填进来 —— 那个 key 能绕过策略读写整张表。

还没有表？先在 Supabase 控制台的 SQL Editor 里跑一次仓库里的 docs/supabase-setup.sql。 各台机器装完即连（地址与 key 已内置在安装包里），不用手填；要换项目走「高级设置 → 云端协作 → 导入配置」。
